# Zero Indicator downloads

This repository only holds the installers of **Zero Indicator**, a free performance monitor
(temperatures, CPU/GPU load, FPS, overlay box). No ads, no account, no tracking.

Get the right file on the **Releases** page (or from the official website):

| Platform | File |
|---|---|
| Mac (macOS 14 or newer, Apple chip and Intel) | `ZeroIndicator-1.0-mac.dmg` |

Each release lists the file's SHA-256 fingerprint so you can check your download.
